# Royal Agate Export — Starter Project

Frontend: React + Vite + Tailwind CSS  
Backend: Django + Django REST Framework  
Database: PostgreSQL

## Install
Backend:
1. `cd backend`
2. Create and activate a virtual environment.
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and configure PostgreSQL credentials.
5. `python manage.py check`

Frontend:
1. `cd frontend`
2. `npm install`
3. `npm run dev`

This ZIP provides the agreed folder scaffold and starter configuration. It is not a finished e-commerce application: models, APIs, business rules, payment verification and tests still need implementation and client approval.
